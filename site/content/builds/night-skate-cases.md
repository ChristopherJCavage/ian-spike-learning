## How It Works

One loop, built once in Case 1 and changed a little in each case after.
The battery holder rides the top edge of the mini grid. A slide switch,
a red-and-yellow light with the egg on it, and three blue wires close
the circle. Nothing here is a SPIKE™ program, so there is no screenshot.

Each case is one new idea:

1. No circle, no light. A switch, or a missing wire, is a gap.
2. Some parts care which way round they go. Turn the light and it
   changes color.
3. The button only lets power through while you hold it. The horn was
   quiet because it was in backwards.
4. One switch can run two lights, if each light has its own way back.
5. Guess first, then test it. Three missions, and no step pages.

## What You Need

- One Elenco® Snap Circuits® Beginner set (SCB-20) and one Snap
  Circuits® Jr. set (SC-100). Every block is from the Beginner box
  except one extra blue 3-snap wire, which Case 4 takes from the Jr. box.
- Three AA batteries. A grown-up puts them in and takes them out.
