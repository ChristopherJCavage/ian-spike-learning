# LEGO Education SPIKE Prime 45678 -- Parts Inventory
#
# Official LEGO box count: 528 pieces.
# This teardown (LEGO's own Customer Service replacement-parts registry,
# via Brickset, retrieved 2024-10-27): 557 pieces / 112 unique elements.
# Same gap story as the Essential set -- includes the sticker sheet, and
# LEGO's own recount corrected the 32270 gear qty from 2 to 3 at some point.
# Treat this file as the accurate source for "what's actually in the bin."
#
# Format (pipe-delimited, grep-friendly):
#   QTY | COLOR | PART NAME | CATEGORY | DESIGN_ID | ELEMENT_ID
#
# Examples:
#   grep -i "motor" parts.txt
#   grep -i "sensor" parts.txt
#   awk -F'|' '{print $2}' parts.txt | sort | uniq -c   # pieces per color
#
# Two rows sharing a DESIGN_ID/name/color are LEGO manufacturing-revision
# variants of the same physical part -- only one revision ships per box.
