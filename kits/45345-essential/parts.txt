# LEGO Education SPIKE Essential 45345 -- Parts Inventory
#
# Official LEGO box count: 449 pieces.
# This teardown (LEGO's own Customer Service replacement-parts registry,
# via Brickset, retrieved 2024-10-27): 473 pieces / 141 unique elements.
# The gap is normal -- LEGO's replacement-parts count includes the sticker
# sheet and counts a few small connectors slightly differently than the
# box blurb. Treat this file as the accurate source for "what's actually
# in the bin," not the marketing number.
#
# Format (pipe-delimited, grep-friendly):
#   QTY | COLOR | PART NAME | CATEGORY | DESIGN_ID | ELEMENT_ID
#
# Examples:
#   grep -i "motor" parts.txt
#   grep -i "connector" parts.txt
#   awk -F'|' '{print $2}' parts.txt | sort | uniq -c   # pieces per color
#
# Two rows sharing a DESIGN_ID/name/color (e.g. the two "HUB, NO. 12" rows)
# are LEGO manufacturing-revision variants of the same physical part --
# only one revision ships in any given box, they are not both present.
#
# Build-tester note (chameleon build-test, Sep 2026): a draft pass briefly
# recoloured both hub rows to White off a table photo taken for an
# unrelated point (the eye-peg build). Checked against LEGO's own parts
# catalogue (Brickset, element 6412840 / design 100885): Bright Yellow,
# RGB #FAC80A, "no white variant" for this element. Left as Bright
# Yellow below, matching the teardown source and the LDraw library's
# "Yellow Bottom" part.
