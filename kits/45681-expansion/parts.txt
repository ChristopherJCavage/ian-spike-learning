# LEGO Education SPIKE Prime Expansion Set 45681 -- Parts Inventory
#
# Official LEGO box count: 604 pieces.
# This teardown (LEGO's own Customer Service replacement-parts registry,
# via Brickset, retrieved 2024-10-27): 606 pieces / 105 unique elements.
# Same +2 gap story as the other two kits -- LEGO's replacement registry
# counts a couple of items the box blurb rounds off. Treat this file as
# the accurate source for "what's actually in the bin."
#
# This is an ADD-ON, not a standalone kit. It has no hub and no battery.
# It ships one extra Medium Angular Motor and one extra Color Sensor, and
# otherwise it is gears, turntables, big wheels, and a lot of beams.
#
# Format (pipe-delimited, grep-friendly):
#   QTY | COLOR | PART NAME | CATEGORY | DESIGN_ID | ELEMENT_ID
#
# Examples:
#   grep -i "turntable" parts.txt
#   grep -i "gear" parts.txt
#   awk -F'|' '{print $2}' parts.txt | sort | uniq -c   # pieces per color
#
# Part names are deliberately spelled the same as in the Essential and
# Prime files when the DESIGN_ID matches, so one grep spans all three
# kits. Two rows sharing a DESIGN_ID/name/color are LEGO manufacturing-
# revision variants of the same physical part.

# --- What this set actually adds that the other two bins do not have ---
# - Turntables: Z28 and Z60 (two revisions of the Z60 top), upper + lower
#   halves. This is the first real rotating platform in the collection --
#   crane cabs, radar dishes, tank turrets.
# - Big wheels: 4x WHEEL DIA. 88X14.34 W/ CROSS HOLE (49295). Much larger
#   than Prime's DIA.56 wheels. Note they take a cross axle directly, no
#   separate rim/tyre pair.
# - Gear variety: bevel gears (32198), conical wheels Z12/Z20/Z36,
#   angled gear wheels Z20 and Z28, 7M rack, and 8x quarter-circle gear
#   rack 11X11 (43038) -- a curved rack is new to the collection.
# - Volume connectors: 80x black friction peg, 36x blue 3M peg, 24x blue
#   friction bush w/ cross (43093), 16x 1/2 bush. Realistically this set
#   is where the pins come from now.
# - Long axles: 32M (13927) and 12M (3708) beat anything in the base kits.
# - A chicken.
