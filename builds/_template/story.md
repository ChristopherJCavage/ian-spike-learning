# Story

Optional. Narrative slides that come before step 1. Delete this file if the
build goes straight to bricks. Rules: `context/instruction-screens.md`.

Cast from the Essential four (Leo, Maria, Daniel, Sofie). Art is
`renders/story-NN.png`. Leave `camera` as `-` for drawn art; give the last
slide a camera (lower and more side-on than the `55 225` step default) so
`pages.py render` draws the finished model there instead of an illustration.
`overlay` is an optional second image laid on the corner of the art.

These pages get printed, so they carry no Back/Next chrome.
