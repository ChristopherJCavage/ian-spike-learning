# LeoCAD PNGs

Instruction stills `step-001.png` … `step-023.png` (LeoCAD CLI, camera
and highlight per `screens.md`, previous steps faded). Step 24 (program)
has no render -- it's a coding page, no new bricks. Check views of the
finished truck:

- `check-left.png` -- side profile (front to the right)
- `check-front.png` -- looking at the drill / sensor eyes
- `check-top.png` -- plan view
- `check-iso.png` -- default instruction camera 55 225

The PNGs are RGBA with a transparent background. `--fade-steps` writes
prior parts at half alpha; drop them on a white page and the history
goes grey while the new piece stays in colour.
