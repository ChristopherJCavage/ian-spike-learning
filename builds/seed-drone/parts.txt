# 13360 small eye tile 2/4; Hub 1/1.
#
# The tray floor was four 3709 plates and is now two. Three lay end to end
# for a 6x4 floor and a fourth went underneath to tie them together, because
# plates side by side do not clutch each other. Turning both plates to run
# fore-and-aft instead lets the two 1x4 side walls span the seam and do that
# job, so the bridge is not needed. Same rigidity, two plates back in the box.
#
# Zero-spare warnings: both 4519 yellow 3M axles and both 64290 purple 11M
# beams are used. Pull those before class -- the rotor cannot be built twice
# from one box.
#
# 4519 used to read 4/4 here and the rotor used four axles, two per blade.
# The box holds two. kits/45345-essential/parts.txt said four and was wrong,
# the same way it said four grass stems when there are two -- see
# builds/rainforest-drop-zone/README.md, "the kit list can invent parts."
# Each blade now takes one yellow axle plus one black friction peg, and which
# fastener goes in which hole matters: the axle is a cross and only grips the
# dark-green brick's CROSS holes at x=+-20, while the peg is ribbed and grips
# the plate's ROUND holes. Put the axle in a round hole alone, as the first
# version did, and it spins and slides straight out -- the blades came off the
# real model. ldrcheck grew a NOT RETAINED check out of this.
#
# The eye tiles are the one printed part in this build. Kit 13360 (element
# 6284599) is 98138pr0008: a 1x1 round tile with a black iris and pupil.
# The kit ships four. The chameleon wears two and the drone wears the other
# two, so the two models can sit on the table together -- but that is the
# whole supply, and neither model has a spare pair.
#
# An earlier version used the LARGE printed eye instead: 2x 44690 (element
# 6252746, 14769pr1116, blue iris) lying flat on the face plate at x = +/-60.
# They came off. Flat on the deck and 120 LDU apart they faced the sky, not
# the room, so from in front they read as two instrument dials; and once the
# sensor grew its own pair of eyes, keeping both gave the drone four. All
# four large eyes -- 2x 44690 plus 2x 113420, the same print on a later
# mould -- are now untouched by this model.
