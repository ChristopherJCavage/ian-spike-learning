# Code -- Hot Press

Icon Blocks. The Hub sits beside the press.

- Light matrix on port A, stood in front, lights toward the room.
- Small Angular Motor on port B. It is pinned to the tower, so nobody
  has to hold it.

Start with the press open (the hub peg at the top). One stack, on the
yellow play button:

1. Matrix red.
2. Motor half a turn. The press comes down onto the wood.
3. A sound, played until it finishes. Icon Blocks have no plain wait,
   so the sound is the squeeze at the bottom.
4. Motor half a turn more, the same way. The press goes back up.
5. Matrix green.

Both turns go the same way, so the hub goes all the way round once, the
way a real press runs. Tap play again to press again.
